# ADR: Use Python for the MVP

Status: Accepted

## Context
Morning Digest needs RSS/HTTP, AI integration, HTML, JSON, and automation with low MVP overhead.

## Decision
Version 1 SHALL be implemented in Python. Python 3.11+ SHALL be supported; Python 3.13 SHOULD be the reference runtime.

## Consequences
Mature ecosystem and simple GitHub Actions integration; Python compatibility becomes an implementation constraint.

Accepted ADRs are normally preserved. A later ADR may supersede this decision.
