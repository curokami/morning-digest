# ADR: Use a controlled Taxonomy

Status: Accepted

## Context
Source tagging systems differ in vocabulary and granularity.

## Decision
Morning Digest SHALL maintain `data/taxonomy.yaml`. Digest Tags SHALL come only from it; Source Tags are contextual metadata.

## Consequences
Consistent cross-source classification; taxonomy requires maintenance.

Accepted ADRs are normally preserved. A later ADR may supersede this decision.
