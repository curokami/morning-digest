# ADR: Make Recommendation a core domain concept

Status: Accepted

## Context
The product should prioritize reading rather than claim an intrinsic Importance Score.

## Decision
Recommendation SHALL contain Reading Priority, Reason to Read, and Digest Tags. Importance Score SHALL NOT be a domain concept.

## Consequences
The model reflects user-oriented value; recommendation quality depends on useful context and prompt quality.

Accepted ADRs are normally preserved. A later ADR may supersede this decision.
